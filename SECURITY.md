# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability reporting:

- open the repository's **Security** tab and choose **Report a vulnerability**, or
- go straight to <https://github.com/sh1ny/correlia/security/advisories/new>.

Don't open a public issue, discussion or pull request for a vulnerability or a leaked secret. Include what you found, how to reproduce it, and what an attacker could do with it. The report stays private until a fix is released, and you're credited in the advisory unless you'd rather not be.

## Supported versions

Correlia has no stable release yet; fixes land on `main` only.
