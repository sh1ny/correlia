# Plan

The long-form plan behind `openspec/roadmap.md`. The roadmap stays short (Specwright format), and these
files keep the detail.

| File | What it holds |
|---|---|
| [milestones.md](milestones.md) | Every planned feature per milestone, M1 to 1.0, with exit criteria |
| [integrations.md](integrations.md) | The integration catalog (P0/P1/P2/Avoid), plugin capabilities, definition of done |
| [acceptance-scenarios.md](acceptance-scenarios.md) | Named regression scenarios from the legacy defects and common design flaws |
| [open-decisions.md](open-decisions.md) | Choices made with defaults during autonomous planning, waiting for the owner |

The design rationale is in `openspec/strategy.md`, `openspec/architecture.md` and `docs/adr/`. The evidence
is in `docs/research/`.

Planned autonomously on 2026-11-03, on the owner's instruction. Every default in `open-decisions.md` is an
assumption until the owner confirms it.
