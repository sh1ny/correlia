## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Environment -> Settings | Deployment environment supplies `DATABASE_URL` and config-path values that must validate before readiness. |
| Service -> PostgreSQL | Readiness plumbing opens a database connection and executes a fixed query. |
| Package registry -> local environment | uv installs Python packages marked `[ASSUMED]` in research because slopcheck was unavailable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | `Settings` | mitigate | Use `pydantic-settings` with typed fields, `PostgresDsn`, literal environment/log-level values, and `extra="forbid"`; malformed config fails readiness. |
| T-01-02 | Denial of service | `check_database_ready` | mitigate | Execute only fixed `text("select 1")` with no user input; FastAPI route-level timeout/error-shaping is owned by Plan 01-05. |
| T-01-03 | SQL injection | `check_database_ready` | mitigate | Use fixed SQLAlchemy `text("select 1")` with no request or env interpolation. |
| T-01-04 | Elevation of privilege | YAML handling | mitigate | Do not implement concrete YAML loading in this plan per D-18; acceptance forbids `yaml.load(` outside `safe_load` anywhere created by this plan. |
| T-01-SC | Tampering | PyPI package installs | mitigate | Blocking human package verification for all `[ASSUMED]` packages before uv install; stop on package-name/publisher mismatch. |
</threat_model>
