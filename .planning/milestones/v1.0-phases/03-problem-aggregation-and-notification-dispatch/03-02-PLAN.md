<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| YAML plugin registry → Python plugin objects | Operator-controlled config selects trusted plugin classes and options. |
| Correlia → SMTP server | Notification content leaves the process through an external network service. |
| Async handler → background task lifecycle | Exceptions can occur after request processing has moved on. |
| Package registry → project dependency graph | New SMTP dependency enters `pyproject.toml` and `uv.lock`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-E | Elevation of Privilege | `app/plugins/loader.py` | mitigate | Use `yaml.safe_load`, strict Pydantic validation, duplicate-name rejection, and `app.plugins.outputs.` module allowlist; reject `eval`, `exec`, unrestricted import, and unsafe YAML APIs. |
| T-03-02-I | Information Disclosure | `PluginStatus` and registry listing | mitigate | Return only safe name/type/status/hash fields; never expose options, SMTP credentials, rendered message bodies, or exception traces. |
| T-03-02-D | Denial of Service | `AsyncIOTaskRunner` | mitigate | Track task handles, retrieve exceptions, and provide deterministic `drain()` so shutdown does not leak tasks. |
| T-03-02-T | Tampering | task payloads | mitigate | Copy mapping payloads on submit and pass plain serializable values, not ORM objects or live sessions. |
| T-03-SC | Tampering | `aiosmtplib` dependency install | mitigate | Blocking human legitimacy checkpoint before `uv add aiosmtplib`; `[ASSUMED]` packages are not installed automatically. |
</threat_model>
