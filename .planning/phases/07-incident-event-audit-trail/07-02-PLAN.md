<objective>
Refactor Phase 7 plan 07-02 so ingress owns the accepted-event database transaction for AUD-02, AUD-03, and AUD-04, while preserving Correlia's incident decisions and notification envelope behavior.

Purpose: Audit rows must be crash-safe and observational. D-01 and D-02 require the audit insert to land atomically with incident upserts or source-recovery lifecycle writes; D-03 keeps notification submission after commit; D-12 and D-14 define how no-op, below-threshold, replay, and multi-incident recovery events are correlated.

Output: Commit-free manager result objects, ingress-owned incident/audit transaction wiring, post-commit notification submission, and Testcontainers-backed regression coverage proving exactly one audit row per accepted event path without using audit data for decisions.
</objective>
