<objective>
Implement Phase 6 canonical incident API operation parity for API-01 through API-07 and locked decisions D-01 through D-17 on the existing `/v1/incidents` router.

Purpose: Vigilo-shaped clients need offset/list metadata, ACKNOWLEDGED filtering, detail fetches, status PATCH, and DELETE close workflows without a separate `/api/v1/incidents` facade, without weakening Correlia's canonical incident lifecycle, and without mutating summaries without an audited domain model.

Output: Updated incident domain contracts, persistence pagination and derived status filtering, canonical router compatibility aliases, and PostgreSQL-backed pytest coverage proving `/v1/incidents` preserves Correlia's rich model while accepting the compatibility operations.
</objective>
