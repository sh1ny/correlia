Implement Phase 5 request-size limiting and in-process route-class rate limiting for SEC-04 and SEC-05, building on the settings and auth route classes from Plan 01.

Output: New middleware package, route classification utility, size-limit middleware, fixed-window limiter, app factory wiring, safe structured logging keys, and tests for Content-Length, chunked bodies, rate-limit identity, 429, and Retry-After.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External client → ASGI receive channel | Untrusted Content-Length headers and streaming body chunks enter middleware before FastAPI parsing. |
| External client → rate limiter | Untrusted Authorization headers and client addresses become rate-limit identities. |
| Middleware → route handler | Middleware decides whether body bytes and requests may reach domain logic. |
| Security control code → structured logs | Control events cross into logs that must not contain secrets or raw payloads. |
