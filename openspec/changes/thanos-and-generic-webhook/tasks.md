# Tasks

## Test map

Paths are relative to the repository root. Tiers follow AGENTS.md: `test/unit` is fast; `test/db` uses the `db`
tag; `test/e2e` uses the `e2e` tag and real `bin/main.dart` children. Every new `withServerpod` call names its
tier tag.

Scenarios that only real Thanos Ruler releases can produce map to named tests in `thanos_versions_test.dart`, which
re-evaluate the committed captures and their manifest (group 2). A row turns green only when its capture is
committed and its test passes.

Rows marked `green` are unchanged scenarios inside MODIFIED requirements whose existing test already passes; their
group re-runs that test. Every other row starts `red` and turns green when its group's test passes.
